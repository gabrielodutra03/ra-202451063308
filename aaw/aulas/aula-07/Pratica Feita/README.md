Roteiro Prática:

1. Injeção SQL(Prints Postman):

Um atacante poderia burlar a busca e acessar dados que não deveriam ser retornados.


2. IDOR: (Prints Postman):

Um atacante poderia simplesmente alterar a Url e acessar dados de outros usuários sem permissão. Teria acesso a acessar qualquer recurso de outros usuários.

3. Segredo no Código: (Prints Postman):

Um atacante pode ter acesso a informações do código, como: nome de classes, nome de métodos, tecnologia utilizadas, detalhes das configurações, etc.

4. Mass Assigment: (Prints Postman):

O atacante pode modificar campos que seriam somente realizados pelos administradores. A depender das permissões dadas ao admin, o atacante poderia acessar diversos comandos e funçoes internas.
